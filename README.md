# GameHub Store

GameHub is an online game store built with HTML, CSS and vanilla JavaScript. The site fetches games from the Noroff GameHub API and allows users to view product details, add games to a cart, and complete a checkout flow.

## Improvements made for Portfolio 2

- Redesigned the visual style to feel warmer and more inviting.
- Replaced the plain black background with a softer dark gradient.
- Improved product card layout, spacing, border radius and hover interactions.
- Improved button styling and focus states for better accessibility.
- Added loading and error messages for API content.
- Improved cart feedback by replacing browser alerts with a toast message.
- Added lazy loading to product images.
- Improved responsiveness across desktop and mobile.
- Fixed checkout navigation so it works with relative paths.

## Built with

- HTML
- CSS
- Vanilla JavaScript
- Noroff GameHub API

## Pages

- Home page with available games
- Game details page
- Cart page
- Checkout page
- Confirmation page
- About page
- Contact page

## Setup

1. Clone the repository.
2. Open `index.html` in a browser, or use a local server such as Live Server in VS Code.
3. Make sure you have internet access so the GameHub API can load products.
